# Haynes Quest

[GitHub repository](https://github.com/thaynes43/haynes-quest)

A 3D browser game for the Haynes kids, with real photos from Immich as the things players collect.

This repository starts with the project brief and documentation templates. Gameplay details and the runtime stack will follow Tom's next brief. Deployment will live in `haynes-ops` on the local cluster.

Start with the [project brief](docs/prds/001-project-brief.md), then the [documentation index](docs/README.md). Current work and the next step live in [`.agents/HANDOFF.md`](.agents/HANDOFF.md).
